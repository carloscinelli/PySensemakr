# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inclusive environment for everyone who participates in the PySensemakr project.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive feedback
- Focusing on what is best for the community

## Scope

This Code of Conduct applies within all project spaces, including the issue tracker, pull requests, and any other communication channels associated with the project.

## Attribution

This Code of Conduct is adapted from the Contributor Covenant, version 2.1, available at https://www.contributor-covenant.org/version/2/1/code_of_conduct.html.
